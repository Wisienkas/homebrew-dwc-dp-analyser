# Nreibke Dwc-dp-analyser

## How do I install these formulae?

`brew install nreibke/dwc-dp-analyser/<formula>`

Or `brew tap nreibke/dwc-dp-analyser` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nreibke/dwc-dp-analyser"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
